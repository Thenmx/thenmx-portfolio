FROM CONCEPT TO EVALUATION

The project started as a Photo Enhancer concept. After presenting the idea to a senior product stakeholder, one question reframed the exploration: how do you determine which AI workflow actually performs better?

That feedback shifted the project from image generation to workflow evaluation, introducing explicit criteria for visual quality and fidelity.

04 / CHALLENGES / WHAT THE SYSTEM HAD TO SOLVE
CHALLENGES SOLVED

Preserving property fidelity

PROBLEMAI enhancement can improve visual quality while silently altering geometry, materials, furniture or objects.
APPROACHEvery enhanced image is compared with the original across four structural dimensions before entering the recommendation stage.
FINDINGTests identified visually improved outputs that were not sufficiently faithful to the source property and were therefore rejected.

Comparing different workflows

PROBLEMDifferent AI enhancement workflows can produce significantly different results from the same source image.
APPROACHEvery candidate is evaluated through the same shared framework using Fidelity, Quality Improvement, Cost and Processing Time.
FINDINGThe evaluation layer can compare different enhancement workflows without changing the underlying assessment logic.

Turning evaluation into a recommendation

PROBLEMThere is no universally best workflow: the optimal choice depends on the business context.
APPROACHThe Recommendation Engine combines fidelity, visual quality, cost and processing time after candidates pass the Fidelity Gate.
CURRENT STATEThe engine is functional, while criterion weighting is still being calibrated around different business priorities.
